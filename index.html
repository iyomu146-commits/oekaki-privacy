プライバシーポリシー

アプリ名：おえかきひろば（Oekaki Hiroba）
最終更新日：2026年7月6日

本プライバシーポリシーは、子ども向けお絵かきアプリ「おえかきひろば」（以下「本アプリ」）における情報の取り扱いについて説明するものです。本アプリは主に未就学児から小学生のお子様が利用することを想定して設計されており、私たちはお子様のプライバシー保護を最優先に考えています。

大切なポイント
  • 本アプリは、氏名・住所・メールアドレス・電話番号・位置情報などの個人を特定できる情報を収集しません。
  • お子様が描いた絵は、原則としてお使いの端末の中だけに保存されます。
  • 「AIはんてい」機能を使ったときだけ、描いた絵の画像が判定のために外部のAIサーバーへ送信されます（詳細は下記）。

1. 収集しない情報

本アプリは、お子様や保護者の以下の情報を収集・要求しません。

  • 氏名、住所、メールアドレス、電話番号などの連絡先情報
  • 生年月日、性別などの属性情報
  • 位置情報（GPS）
  • 連絡先、写真ライブラリ、カメラ、マイクへのアクセス
  • アカウント登録やログイン情報

2. 端末内に保存される情報

以下の情報は、お使いの端末の中（ローカルストレージ）にのみ保存され、私たちのサーバーには送信されません。

  • 描いた作品（ギャラリー）：「ほぞん」した絵は、端末内に縮小画像として保存され、アプリ内の「さくひん」で見返せます。アプリを削除すると消去されます。
  • ランダムな端末識別子：「AIはんてい」の1日の利用回数を数えるためだけに使う、ランダムな文字列です。個人を特定するものではありません。
  • 利用回数の記録：その日の判定回数のみを記録します。日付が変わるとリセットされます。

3.「AIはんてい」機能について

本アプリには、描いた絵をAI（人工知能）が見て「なにに みえるか」を答える「AIはんてい」機能があります。この機能をお子様が使ったときにのみ、次の処理が行われます。

  • 描いた絵の画像が、私たちが運用する中継サーバー（Cloudflare Workers）を経由して、AIサービス提供元である Anthropic 社の API に送信されます。
  • 送信されるのは絵の画像と、回数管理用のランダムな端末識別子のみです。氏名などの個人情報は一切含まれません。
  • 送信された画像は判定結果を返すために使われます。Anthropic 社のポリシーにより、送信された画像はモデルの学習（訓練）には使用されず、原則として受信から30日以内に同社のサーバーから自動的に削除されます（法令遵守や不正利用の防止に必要な場合を除く）。
  • 判定結果（絵文字と短いコメント）はお子様の端末に表示されます。

Anthropic 社のデータの取り扱いについては、同社のプライバシーポリシーもあわせてご確認ください。

4. 広告について

本アプリは、無料でご利用いただくために、Google 社の広告サービス「Google AdMob」を利用して広告を表示することがあります。

  • 本アプリは子ども向けアプリであるため、AdMob の子ども向け設定を有効にし、お子様の興味関心に基づくパーソナライズド広告（追跡型広告）は配信しません。
  • 広告の配信にあたり、AdMob は広告の表示や不正防止のために、端末に関する限られた情報（広告識別子等）を扱う場合があります。
  • Google 社によるデータの取り扱いについては、Google のプライバシーポリシーをご確認ください。

5. 保護者の皆さまへ

本アプリはお子様が安全に楽しめるよう配慮していますが、「AIはんてい」機能は外部サーバーへ画像を送信します。お子様がどの機能を使うかについては、保護者の方が見守っていただくことをおすすめします。ご不明な点やご要望がある場合は、下記の連絡先までお問い合わせください。

6. 情報の第三者提供

私たちは、上記に記載したAI判定機能および広告配信の目的を除き、収集した情報を第三者に販売・提供することはありません。法令に基づき開示が求められた場合を除きます。

7. お子様の情報の保護

本アプリは13歳未満のお子様の利用を想定しています。私たちは、お子様から個人を特定できる情報を意図的に収集することはありません。万一、保護者の同意なくお子様の個人情報が送信されたことが判明した場合は、速やかに削除いたします。お心当たりのある場合は下記までご連絡ください。

8. 本ポリシーの変更

本プライバシーポリシーは、機能の追加や法令の変更に応じて改定されることがあります。重要な変更がある場合は、本ページ上で更新日とともにお知らせします。
